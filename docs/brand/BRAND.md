# AMICO brand

![AMICO Cameroon logo](amico-logo.jpg)

**AMICO Cameroon** — Alpha Multi-Integrated Corporation. Product name in apps and receipts: **AMICO**.

Tokens live in [`packages/brand`](../../packages/brand/src/index.ts) and are shared by the mobile app, the customer web and the admin dashboard.

| Token | Hex | Use |
| --- | --- | --- |
| `navy950` | `#0E1116` | App background (dark) |
| `navy900` | `#191B27` | Cards and surfaces |
| `gold500` | `#F09E32` | Primary buttons, highlights |
| `gold300` | `#FFCB60` | Glow, focus, active states |
| `gold700` | `#B8731F` | Primary on light backgrounds (contrast) |
| `bronze500` | `#9C724C` | Wordmark, secondary text on dark |
| `simulation` | `#8B5CF6` | SIMULATION banner only — never gold, so it can't read as real money |

Typography: a classic serif for the wordmark and headings (Cinzel or similar), a clean sans (Inter) for UI text.

The supplied logo is a photographic JPEG (1080 × 1005). For app icons, splash screens and favicons, ask the designer for a vector (SVG) or a transparent PNG at 1024 × 1024 of the sphere alone.
